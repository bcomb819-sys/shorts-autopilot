How to get free YouTube OAuth credentials & enable YouTube Data API v3
  1. Open console.cloud.google.com → Create/select a project → Enable YouTube Data API v3.
  2. Go to OAuth consent screen / Audience → add your Gmail(s) under Test users.
  3. Go to Credentials → Create OAuth Client ID (Web application) with Redirect URI: http://127.0.0.1:3456/api/youtube/callback.
  4. Paste the Client ID & Secret above, click Save OAuth Credentials, then click + Add YouTube Account.
